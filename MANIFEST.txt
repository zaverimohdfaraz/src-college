SRCC website — update package 2 (18 Nov 2026)
=============================================
This package REPLACES the earlier srcc-website-update.zip and includes everything in it.
Unzip over your srcc-website folder, overwrite when asked, then push and redeploy.
No new packages, so no npm install is needed.

WHAT CHANGED
1. Logo: refined crest + college name as sharp text in header, mobile menu and footer
   (public/emblem.webp, src/components/Brand.tsx). New favicon and phone home-screen icon.
2. Name: "Shri Ram College of Commerce & Science" across the site, titles, emails and README.
3. Homepage slider on phones: the slider now grows to fit its text, so the headline no longer
   slides under the header on iPhones/Android. Slightly smaller headline and tighter spacing
   on phones; stronger shading behind the text so it reads clearly over the photo.
4. Design polish:
   - Photos gently uncover as you scroll to them (CSS only, off for reduced-motion users).
   - Photos zoom slightly on hover.
   - "Why Shri Ram College" section now has a photo beside the heading.
5. Header navigation fits on one line with the new logo; header fits 320px phones.
   Footer phone numbers each on their own line.
